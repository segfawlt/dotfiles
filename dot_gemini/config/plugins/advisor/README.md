# Persistent Advisor Subagent Plugin (`advisor` v3.0)

1. **Isolated Zero-Tool 1-to-1 Continuous Advisor (`advisor-core`)**:
   - Each mutating session (`Lead` + `self` subagents; read-only `research` / `image-generator` / `*` default to `off`, classified on Turn 1 directly from `HookArgsCommon`) gets its own persistent `--conversation <advisor_cid>` launched via `--agent advisor-core` (`tools: []`, `excludeDefaultComponents: true`, `inheritCustomizations: false`, `inheritMcp: false` — ~800-token baseline instead of ~13K inherited prompt bloat).
2. **Continuous Memory + Virtual-Cursor Incremental Turn Slices**:
   - Bootstraps Turn 1 with `~/.agents/memories/<repo>/memory_summary.md` (`<memory-context>`), `~/.agents/advisor/ADVISOR.md`, and hierarchical `WATCHDOG.md` (`@path` imports).
   - Feeds strictly `max_chars`-bounded incremental `transcript_cursor` deltas on Turn 2+ across normal, 202-line sliding-window, `agy --conversation` resumed, and TUI-rewound transcripts (recovering untruncated prompts from `transcript_full.jsonl` without duplicating anchors and coalescing read-only bursts), with single-turn `PLANNER_RESPONSE` token accounting, dangling-turn recovery, and automatic `90,000`-token context rollover.
3. **Commit-Aware, Pre-Dirty-WIP-Isolated & Tier-Budgeted Finish-Line Diff Checks (`Stop`)**:
   - Captures per-repo `(turn_start_head, pre_dirty_hashes)` baselines under per-session `fcntl.flock` (`turn_open` state machine across `PreInvocation -> PostToolUse -> Stop`, including delegated `invoke_subagent` mutations and git submodule `SUBMOD:` signatures while excluding nested `.worktrees/`) so green-milestone `git commit`s (`<turn_start_head>..HEAD`), `git commit --amend` / root / rewound commits, uncommitted `git mv` renames, and turn-edited working-tree / untracked files are reviewed accurately, while pre-existing untouched dirty WIP and pure Q&A / read-only turns cost `0` Advisor tokens.
   - Prioritizes Tier-1 source hunks ahead of Tier-2 test/spec/asset files with full `git diff --stat` summaries on large diffs, defers `Stop` review only while non-daemon `<uuid>/task-<N>` tasks remain in flight (`IsDaemon: true` dev servers, one-shot `schedule` wakeups, and `TimerCondition`-cancelled timers never block review), and uses `--print-timeout` + process-group `SIGKILL` cleanup.
4. **Inline TUI Pushback Banners + Thrash Circuit-Breaker (`PreInvocation`) & EmissionGuards**:
   - Renders zero-model-token inline `Advisor (<model>) — Pushback / Thrash Pivot` banners (`errorMessage.userMessage` -> `ShouldShowUser=true, ShouldShowModel=false`, scoped to active continuations and automatically suppressed in `-p` headless mode and subagents) whenever `Stop` or `PreInvocation` intervenes.
   - Injects a concrete pivot diagnosis after `>= 3` consecutive tool/shell failures (including non-zero `run_command` exit codes from `transcript.jsonl`); enforces automatic `fallback_model` retry with cross-model resume continuity, 3-failure drop latch, rank-aware `EmissionGuard` (`warning -> critical` escalation + filler suppression), and output hazard quarantine.
5. **Telemetry, Live Logs & Automated Tests**:
   - First-class `agy stats` attribution (`By agent`, `Subagents`, and multi-hop parent `Traces`) + live event log at `~/.agents/advisor/advisor.log` (`agy advisor logs -f`).
   - Run the 18-test automated unit + subprocess integration suite: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -v -s ~/.gemini/config/plugins/advisor/tests -p 'test_*.py'`
